# 🚀 MiMo Downloader Panel

**Fast • Lightweight • Powerful**

This is the official frontend panel for the MiMo Social Media Downloader API. It allows users to download videos, audios and images from Facebook, Instagram, TikTok, Pinterest, and YouTube.

## 📋 Prerequisites

Make sure you have **Python 3.8+** installed on your system.

## 💻 How to Run Locally

1. **Clone or download** this project folder.
2. **Install the required dependencies**:
   ```bash
   pip install -r requirements.txt
3. **Start the panel**:

   ```bash
   python main.py
4. **Open your browser and go to**:

   ```text
   http://127.0.0.1:5000/

## ⚙️ How It Works
This panel acts as a frontend interface. When you paste a link and click "Fetch", it securely sends a request to the main API server hosted at http:// to fetch the media details.

No API keys or server-side code are required on your end.
